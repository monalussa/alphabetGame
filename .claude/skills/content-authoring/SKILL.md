# Content authoring

## Model

- **Concept** = a language-neutral thing with one picture: `content/concepts/concepts.json`
  `{ "pineapple": { "imageId": "pineapple" } }`. Pictures are reused by every language.
- **Language pack** = `content/languages/<code>/`:
  - `pack.json` — code, name, locale, `matchAccentedInitials`, audio source (`piper` + voice, or `recording`)
  - `letters.json` — per letter: `id`, `letter`, `display` ("A a"), `name` (spoken letter name),
    `keys`, optional `character`, `words` (2–3; 3 preferred) or `"skip": true`
  - `ui.json` — interface strings
  - `characters/` — that language's letter-character SVGs
  - `audio/` + `audio-manifest.json` — generated by the tools, never edited by hand
  - `recordings/` — raw WAVs from the recorder (gitignored, private)
- **Schemas** in `content/schemas/` are the single source of truth for source files. The runtime pack
  format is built by `tools/src/alphabet_tools/pack_builder.py` and parsed by `src/core/content/parse-pack.ts`;
  change both together (a unit test parses the real built packs).

## Entries per letter

4 entries, played in rotation: character → word 1 → word 2 → word 3.

- Character: `{ "name": "Madame A", "line": "Bonjour, je suis Madame A !", "speech": "… Madame a !" }` —
  our own original character; `speech` is what TTS reads when it differs from `line`. Clip id `char_<letter id>`.
- Word: `{ "id": "ananas", "text": "ananas", "concept": "pineapple" }` (+ optional `speech`). Clip id `word_<id>`.
- Letter name clip: `letter_<letter id>`, spoken from `name`.
  Letters without enough good words get `"skip": true` (their key plays a fun sound).
  Every key that is not a playable letter plays a random fun sound.

## Word rules

- Only words approved by the owner in `content/words-review.txt`.
- Concrete, picturable, friendly, known to a 3–6 year old. No scary, violent or ambiguous words.
- The word must start with the letter; prefer words whose first _sound_ matches (avoid "chat" for C).
- Native-speaker review before audio generation.

## Naming

- Ids: lowercase ASCII `^[a-z0-9_]+$`. Transliterate: `č→ch`, `ć→cj`, `dž→dzh`, `đ→dj`, `lj→lj`, `nj→nj`, `š→sh`, `ž→zh`
  (ids must stay unique within a pack; the validator checks this).
- Files: `<kind>_<id>.<ext>` — `word_ananas.mp3`, `char_a.svg`, `letter_a.mp3`, `fun_boing.mp3`.

## Audio

- Piper (free, offline, open source) for FR (`fr_FR-siwis-medium`, CC BY 4.0) and EN
  (`en_US-ljspeech-high`, public domain). Voices are pinned by revision + SHA-256 in `tools/voices.lock.json`.
- Croatian (and any language with `"source": "recording"`): the owner records with the local recorder page.
- Clips are trimmed, leveled, faded and encoded to mono 48 kbps MP3. Unchanged clips are skipped.

## Commands (run from `tools/`, or via npm from the repo root)

```sh
uv run alphabet-content validate [--strict]      # npm run content:validate
uv run alphabet-content build                    # npm run content:build → public/packs, images, sounds
uv run --group audio alphabet-content audio fr   # Piper speech (or encode recordings for hr)
uv run alphabet-content record hr                # local recorder page on http://127.0.0.1:8765
uv run --group audio alphabet-content fun-sounds # synthesize fun sounds (our own work)
uv run --all-groups pytest && uv run ruff check . && uv run mypy src
```
